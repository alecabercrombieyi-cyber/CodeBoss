# 04 — QA workflow

## Goal
Adversarially audit the research + design + marketing package and find every factual error, weak hook, pacing dead zone, brand violation, and missing on-screen cue BEFORE a single frame is recorded.

## Inputs
- `wat/tmp/coding-output.md`
- `wat/tmp/marketing-output.md`
- `wat/tmp/thumbnail.svg`
- `wat/tmp/title-cards.md`
- `wat/tmp/visual-spec.md`
- Source HTML at `C:/Users/aleca/Desktop/Logistics Suite/Logistics-Suite/site/carrier-analyzer.html`

## Audit dimensions
1. **Factual** — every script claim cross-checked against the HTML. Especially:
   - Tier 1 / Tier 2 / Tier 3 qualification rules — exact load counts and month windows
   - Factoring blocklist behavior (only blocks when remitTo matches AND is not self-remit)
   - External links (Highway URL pattern, FMCSA SAFER, Carrier411)
   - Salesforce/Revenova import path, 26-second simulated timeline, servlet URL
   - localStorage key prefix is `clis_` (NOT `cv_`), since CarrierVet inherited from CLIS
   - CarrierVet does NOT itself pull safety scores or run fraud detection — it surfaces shipment history + factoring flags + deep-links to authoritative sources. Any claim like "automatic fraud detection" or "real-time FMCSA pull" must be killed.
2. **Hook strength** — does the title pull a thumb-scroll? Does the 15-second opener earn a 30-second commitment? Flag generic phrasing.
3. **Pacing** — find dead zones (>90s of static narration), find sections that need a faster visual cut.
4. **Brand** — palette adherence, font usage, no out-of-suite colors, voice stays broker-to-broker.
5. **Footage cues** — every script beat must name a concrete on-screen action. Flag any narration without a paired visual.
6. **Thumbnail readability** — mentally downscale to 320 px wide. Text legible? Hierarchy clear?

## Output
`wat/tmp/qa-report.md` — severity-ranked findings (P0 / P1 / P2), each with a concrete fix.
