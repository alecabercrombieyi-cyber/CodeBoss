# Workflow 04 — QA (adversarial)

## Goal
Try to break every claim, every demo step, every hook. Find the gap before YouTube does.

## Inputs
- `wat/tmp/coding-output.md`
- `wat/tmp/marketing-output.md`
- `wat/tmp/thumbnail.svg`, `wat/tmp/title-cards.md`, `wat/tmp/visual-spec.md`

## Output → `wat/tmp/qa-report.md`
For each of these, list issues found + fix recommendation:
1. **Factual accuracy** — does every feature the script demos actually exist in `freight-matcher.html`?
2. **Pacing** — any chapter longer than 4 minutes? Any under 60 seconds?
3. **Hook strength** — does the cold open earn the next 30 seconds?
4. **Thumbnail clarity** — would a broker scrolling on a phone get it in <1s?
5. **Title vs thumbnail vs first 30 sec** — do all three promise the same thing?
6. **Audience mismatch** — anywhere we sound like a SaaS pitch instead of a broker?
7. **Demo risk** — anything that could blow up live (API rate limit, geocoding timeout, paste-bin format quirks)?
8. **CTA** — is there a single, clear next step (download/visit hub/get key)?

## Self-heal
If everything looks good, push harder. Find at least 3 issues. If still nothing, mark the package "approved with thin QA" and flag it for the final-decision agent.
