# Workflow 03 — Marketing & Trend

## Goal
Package the tutorial for freight-broker YouTube: titles that earn the click without baiting, a description that ranks, tags that fit how brokers actually search.

## Outputs (→ `wat/tmp/marketing-output.md`)
- 5 candidate titles (A/B testable; one "boring/clean", one "curiosity", one "outcome", one "tool/POV", one "we built it")
- Final recommended title + reasoning
- Full description (3 paragraphs + chapters + links)
- 15–20 YouTube tags
- 30-second hook (the first 30 seconds of narration, written cold)
- Trend angle: what's hot in freight YouTube/LinkedIn right now and how this tutorial slots in
- Target audience profile (1 paragraph)

## Constraints
- Titles ≤ 70 chars
- No "shocking" / "you won't believe" / clickbait
- Description must include: free DeepSeek API note (5M tokens, no card), local-only data, Logistics Suite hub link
- Audience is dispatchers, freight brokers, owner-operators — not SaaS buyers
- Avoid "AI agent" jargon; say "AI reads your inbox" or "AI parses messy emails"

## Self-heal
If every title sounds the same, force one to be a single sentence in the broker's own voice ("I built a tool that does my inbox sweep in 60 seconds").
