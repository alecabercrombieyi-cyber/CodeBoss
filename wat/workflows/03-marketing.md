# Workflow: Marketing & Trend

## Goal
Produce title A/B options, description, tags, hook, trend angle, and target audience for a long-form YouTube upload.

## Output
- `wat/tmp/marketing-output.md`

## Required sections
1. **5 title options** — lean on these angles:
   - "Stop fighting your CSV"
   - "Clean broker data in 30 sec" (or 2 min — match script)
   - PII / privacy / vendor sharing
   - "I built this because…" personal angle
2. **Long description** (YouTube-optimized, 1500–3000 chars, includes chapter timestamps placeholder, links)
3. **Hashtags + tags** (15–25, freight + privacy + tools mix)
4. **30-second hook** — first 30 seconds of the video, designed to stop the scroll
5. **Trend angle** — what's hot in freight-YouTube right now (broker layoffs, AI tooling, "broker software you actually use," etc.) and how Data Wash plugs into it
6. **Target audience** — freight broker / ops / data analyst / TMS admin personas

## Voice
- Broker-to-broker, never enterprise
- Acknowledge the pain (sharing data with a vendor and panicking about PII)
- No buzzwords like "synergy," "leverage," "ecosystem"

## Distribution context
- Channel: Logistics Suite YouTube
- Video #6 of a 7-part app series
- Companion: link in description to free tool at logisticssuitev1.pages.dev
