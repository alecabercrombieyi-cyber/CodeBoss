# 01 — Research Workflow

## Goal
Build a complete, source-grounded understanding of Bolt Post so the script writes itself. Bolt Post is the high-throughput sibling to Mass Post; the tutorial only matters if a viewer leaves knowing *exactly* when to reach for Bolt Post and when to stay on Mass Post.

## Constraints
- Truth lives in `Logistics-Suite/site/bolt-post.html`. Cross-check Mass Post in `mass-post.html` when claiming a differentiator.
- Three sub-agents run in parallel: coding, design, marketing.
- Voice stays broker-to-broker. No SaaS jargon ("synergies", "stakeholders").
- All on-screen actions in the script must be reproducible by a viewer with no insider context.

## Done when
- `wat/tmp/coding-output.md` has feature inventory, Mass-vs-Bolt differentiator table, user flows, full long-form script (18–24 min), chapters with timestamps.
- `wat/tmp/thumbnail.svg` (1280x720), `wat/tmp/title-cards.md`, `wat/tmp/visual-spec.md` written.
- `wat/tmp/marketing-output.md` has 5 title A/Bs, description, 15 tags, 15s hook, trend angle, target viewer.
