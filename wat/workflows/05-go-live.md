# Workflow 05 — Go Live (Stage 4)

## Goal
Stamp the GO verdict, commit the package, hand off to the human for record + upload.

## Pre-commit checklist
- [ ] All 8 deliverables exist and are non-empty
- [ ] Thumbnail SVG renders cleanly at 1280x720 (no overflow, no unloaded fonts)
- [ ] Script reading time tested at ~150 wpm = 20-26 min
- [ ] Title is < 70 chars; description has chapters and a clear CTA to the Suite landing page
- [ ] QA report has been reconciled (no open blockers)

## Commit command
```
git add -A
git commit -m "tutorial(03-load-manager): GO — long-form package ready"
```
No push. Human decides when to upload.

## Hand-off note for the human
- Record screen at 1920x1080, 60fps, with the Load Manager app loaded against a representative report (5-20 loads, mix of statuses)
- Mic: any cardioid; the voice is broker-to-broker so don't over-produce
- Cuts on every chapter break; cold-open the hook
- Music: low-bed lo-fi or none; channel preference TBD
