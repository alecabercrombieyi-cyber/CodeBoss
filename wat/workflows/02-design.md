# Workflow 02 — Design Agent

## Goal
Brand-aligned visual package: thumbnail, title cards, on-screen overlays.

## Inputs
- `wat/tmp/coding-output.md` (feature inventory drives the visuals)
- Brand: candy palette (pink #d4738c, cream #faf7f2, purple #9b7bb8, mint #7bc8b5, peach #e8a87c, gold #c8a062), DM Sans + JetBrains Mono
- Pillar's own accent color: gold (#c8a062 / similar)

## Constraints
- Thumbnail: 1280x720 SVG. Pillar/column motif (literal columns or a Greek pillar silhouette) plus the "violations / cores / new cores" tension. Must read at YouTube thumbnail size — bold contrast, ≤4 words of overlay text.
- Title cards: ≥6 cards aligned to chapter markers. Each lists chapter title + 2-3 sub-bullets max.
- Visual spec: list every on-screen overlay, lower third, and callout needed for the script. Note brand colors per element.

## Deliverables
- `wat/tmp/thumbnail.svg`
- `wat/tmp/title-cards.md`
- `wat/tmp/visual-spec.md`

## Self-heal
If thumbnail copy reads as enterprise/SaaS, swap for broker-voice ("WHO STOLE YOUR CARRIER?" beats "Core Carrier Analytics").
