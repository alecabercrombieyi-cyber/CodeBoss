# Workflow 02 — Design

## Goal
Produce a YouTube-ready thumbnail and on-screen visual spec that screams "truck-meets-load match" at a glance, in the Logistics Suite candy/cream palette but respecting Freight Matcher's own flame-on-dark identity.

## Outputs
- `wat/tmp/thumbnail.svg` — 1280x720, big enough to read on a phone preview
- `wat/tmp/title-cards.md` — text + style for each on-screen card the editor will overlay
- `wat/tmp/visual-spec.md` — color tokens, font choices, motion notes, lower-third style

## Constraints
- Thumbnail must communicate three things in <1 second: (a) truck/load matching, (b) AI/map visual, (c) "minutes not hours" speed
- Palette anchors:
  - Logistics Suite cream `#faf7f2` for the chrome
  - Suite candy pink `#d4738c` for the speed/match accent
  - FM flame `#ff4d4d → #ff6b35` for the "fire" elements (match hotspots)
  - Match green `#00d4aa` for "matched"
- Fonts: Outfit (display, like the app) + DM Sans (body)
- Face/eyes optional — the icons (🚛 + 🔥 + 📦) already carry it
- No stock photography. Vector + emoji only.

## Self-heal
If the thumbnail reads as generic "AI freight tool", swap in a literal map silhouette with one fire pin and a truck pin — concrete > clever.
