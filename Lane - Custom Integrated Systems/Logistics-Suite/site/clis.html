About CLIS

CLIS
Carrier Lane Intelligence System

CLIS was born out of a simple frustration: freight brokers spend too much time hunting for carrier contacts on lanes they’ve already covered. The idea was to build a tool that could instantly match a load board paste against historical shipment data and surface the right emails, phone numbers, and margin analytics in seconds.

What started as a basic CSV matcher evolved into a full-featured intelligence platform. The development has been iterative and hands-on — every feature was built in direct response to real workflow needs on the brokerage floor.

Development Timeline
Phase 1 — Foundation
Core CSV parsing engine with auto-detection of multiple file formats. Load board text parser that extracts lane pairs, equipment types, and filters out noise. Multi-format column mapping with the data source verification wizard.
Phase 2 — Dual Contact Modes
Email mode for carrier outreach with margin-sorted results. Phone mode with per-carrier load breakdowns, dispatcher details, and click-to-call. Match mode system from exact city-to-city through broad state-to-state.
Phase 3 — Email Intelligence
16-template email generator with time-based greetings and name personalization. Canvas-based lane image generator showing load details in a spreadsheet-style table. Rich HTML clipboard copy with inline embedded images. One-click mailto with BCC pre-fill and auto-copied email body.
Phase 4 — Core Carrier Detection
Automated monthly analysis identifying carriers with 4+ loads per rep using Actual Delivery Date filtering and load number deduplication. Two-list system: exclusion list for existing cores and green-highlighted target opportunities for lanes served by multiple reps.
Phase 5 — Polish
Three themes (Engraved, Clean, Frost). Custom background images. First-timer tutorial system. Settings persistence. Custom search panel for manual lane entry.

CLIS is a single-file HTML application — no server, no login, no dependencies. All data stays local in your browser. It was designed for the 5-to-50-person freight brokerage that needs powerful tooling without enterprise overhead.
