🔐 Grab DAT Token Bookmarklet

Drag to bookmarks bar. Runs on one.dat.com — sends your current DAT auth token to the local dat-pp-cli serve daemon so CLOVr can pull truck postings, contacts, and rates directly via the API. Token rotates every ~30 min; click this once per session when prompted.

🔐 Grab DAT Token

Daemon endpoints: http://127.0.0.1:53682/token (auth) + http://127.0.0.1:53683/* (data). Start with: dat-pp-cli serve in one terminal, dat-pp-cli auth login in another (or just auth login when token expires).

📦 dat-pp-cli (truck + rate fetcher)

Same local helper that powers Mass Post. Pulls DAT data ~20× faster than scraping — no tab switching, no clipboard. One-time setup:

  1. Download all three files below into a dat-pp-cli\ folder on your Desktop.
  2. Double-click start-dat-daemons.bat. Two small windows appear — leave them open while you work.
  3. Drag the green 🔐 Grab DAT Token bookmarklet above to your Chrome bookmarks bar.
  4. On DAT One, click the bookmark whenever CLOVr prompts (~every 30 min).
